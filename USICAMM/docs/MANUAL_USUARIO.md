# MANUAL DE USUARIO - USICAMM

## Introducción

Bienvenido a la plataforma de exámenes USICAMM. Esta guía te ayudará a completar tu examen.

## Requisitos Previos

1. Computadora con Windows, macOS o Linux
2. Mínimo 2GB de RAM
3. Conexión a internet (recomendada pero no obligatoria)
4. Documento de identificación oficial vigente

## Pasos para Iniciar el Examen

### Paso 1: Ingreso con CURP
1. Ejecuta la aplicación USICAMM
2. Ingresa tu CURP (18 caracteres)
3. Haz clic en "CONTINUAR"

### Paso 2: Carga de Identificación
1. Selecciona tu documento de identificación en formato PDF
2. Verifica que sea legible
3. Procede al siguiente paso

### Paso 3: Términos y Condiciones
1. Lee cuidadosamente los términos
2. Marca la casilla "Acepto los términos"
3. Haz clic en "ACEPTAR"

### Paso 4: Reglas del Examen
1. Lee todas las reglas
2. Asegúrate de entender las restricciones
3. Confirma que estás listo

### Paso 5: Examen
1. Lee cada pregunta cuidadosamente
2. Selecciona una respuesta
3. Haz clic en "SIGUIENTE"
4. Repite hasta completar todas las preguntas

## Durante el Examen

### Cronómetro
- Tienes 300 minutos (5 horas)
- El tiempo se muestra en la parte superior
- El examen se auto-cierra si se agota el tiempo

### Barra de Progreso
- Muestra qué pregunta estás respondiendo
- Indica el porcentaje completado

### Navegación
- "ANTERIOR": Retrocede a la pregunta anterior
- "SIGUIENTE": Avanza a la siguiente pregunta
- "FINALIZAR": Termina el examen antes de tiempo

## Restricciones Importantes

⚠️ **NO PERMITIDO:**
- Cambiar de aplicación (Alt+Tab)
- Abrir navegadores o chats
- Usar audífonos o dispositivos
- Captar pantalla
- Usar celular o tablet

⚠️ **Sistema de Advertencias:**
- Máximo 5 advertencias
- La 6á advertencia cancela el examen
- No hay reembolso por violación de reglas

## Al Finalizar

1. Se muestra tu puntuación
2. Se calcula el porcentaje de acierto
3. Puedes descargar tu comprobante PDF
4. El comprobante se sincroniza con nuestros servidores

## Solucionar Problemas

### El examen se cerraó
Verifica que:
- Estás dentro de la ventana de la aplicación
- No estás usando Alt+Tab
- No has abierto otros programas

### No puedo entrar
- Verifica tu CURP (18 caracteres)
- Confirma que estás registrado
- Intenta de nuevo

### Perdi conexión
- No te preocupes: Los datos se guardan localmente
- Cuando reconectes, se sincronizarán automáticamente

No. El examen es de una sola sesión. Tienes 300 minutos para completarlo.
